# KUKA TAXI

Сайт-такси для Казахстана: пассажиры, водители, админ-панель. Работает в браузере на телефоне и компьютере (можно добавить на главный экран).
Зависимостей нет: нужен только Node.js 22.5 или новее.

## Что внутри

**Пассажир:** вход по коду из WhatsApp, карта, поиск адреса, расчёт цены по тарифам, заказ, поиск водителя в реальном времени, карточка водителя и машины, оценка, история поездок, профиль, русский и казахский.

**Водитель:** анкета авто, загрузка документов, проверка администратором, выход на линию, входящие заказы со звуком, навигатор, учёт заработка (день, 7 и 30 дней), рейтинг. Оплата только наличными. Комиссия 0%, меняется в админ-панели.

**Админ-панель `/admin`:** очередь проверки (фото, код на листе, чек-лист, допуск или отказ с причиной), список водителей (приостановить, потребовать сверку лица), все поездки, настройки (период сверки лица, комиссия, радиус заказов, тарифы).

## Как устроена проверка водителей

1. Водитель присылает 7 фото: селфи с удостоверением и листом с кодом, удостоверение (2 стороны), права (2 стороны), техпаспорт, авто.
2. **Фото хранятся только в оперативной памяти сервера.** Они не пишутся ни в базу, ни на диск, ни в логи. После решения админа, через 12 часов или при перезапуске сервера они исчезают. В базе остаётся только факт решения (кто, когда, одобрено или нет).
3. Админ сверяет по чек-листу и допускает водителя. Без допуска на линию выйти нельзя.
4. Допуск по лицу действует **34 часа** (меняется в настройках). Потом сервер сам снимает водителя с линии, пока он не пришлёт новое селфи с новым кодом. Идущую поездку водитель завершает.
5. Админ в любой момент может приостановить водителя или потребовать внеплановую сверку лица.

Сервер уведомляет админов о новой заявке в WhatsApp (не чаще раза в 5 минут) и водителя о решении.

## Запуск

```bash
cp .env.example .env     # заполните
node server/index.js
```

Первый запуск для проверки без WhatsApp: `OTP_PROVIDER=console DEV_EXPOSE_CODE=1 NODE_ENV=development node server/index.js`. Код будет показан на экране и в консоли.

### Код в WhatsApp (нужен один из вариантов)

- **Green API** (`OTP_PROVIDER=greenapi`, `GREEN_ID`, `GREEN_TOKEN`). Быстрее всего: подключаете обычный номер WhatsApp по QR-коду. Минус: неофициальный путь, номер могут заблокировать при большой рассылке. Возьмите отдельную SIM для сервиса.
- **Meta WhatsApp Cloud API** (`OTP_PROVIDER=meta`, `WA_PHONE_NUMBER_ID`, `WA_TOKEN`, `WA_TEMPLATE`). Официальный путь, надёжнее на росте. Нужен бизнес-аккаунт Meta и одобренный шаблон категории Authentication с кнопкой копирования кода. Уведомления админам и водителям в этом режиме не отправляются (нужны отдельные шаблоны).

### Публикация

Нужен сервер с HTTPS (в приложении стоят `Secure`-cookie и геолокация, которая работает только по HTTPS). Самый простой путь: VPS + Caddy:

```
taxi.example.kz {
  reverse_proxy localhost:3000
}
```

Запускайте через systemd или pm2, базу `data/kuka.db` копируйте в резервную копию.

## Проверка

`npm test` проходит 5 сценариев: безопасность, коды, полный цикл от регистрации водителя до оценки, гонка двух водителей за один заказ, настройки.

## Что нужно сделать до публичного запуска

- **Юридически.** Перевозки пассажиров в Казахстане требуют оформления (ИП/ТОО, требования к перевозчикам и водителям, страхование пассажиров). Обработка персональных данных требует политики конфиденциальности и согласий по закону РК «О персональных данных и их защите». Проконсультируйтесь с юристом. Документы водителей по закону могут понадобиться вам для отчётности: вы сами решаете, что хранить, но сейчас сервер сознательно не хранит ничего.
- **Адреса.** Поиск адресов идёт через OpenStreetMap (бесплатно, лимит около 1 запроса в секунду на весь сервис, данные по Казахстану неполные). Для боевой нагрузки подключите 2ГИС или Яндекс Геокодер: достаточно заменить две функции в `server/geo.js`.
- **Тарифы.** Стартовые цифры примерные. Подгоните под ваш город в админ-панели.
- **Масштаб.** Одна машина с SQLite держит сотни одновременных водителей. Рост выше потребует вынести сессии и очередь в Redis/Postgres.
- **Push-уведомления и приложения.** Сейчас живые обновления идут, пока страница открыта. Для фоновых уведомлений нужно приложение или Web Push.
- **Фото-проверка лица** сейчас ручная (так вы просили). Автоматическое сравнение лиц и проверка на подмену фото потребуют отдельного провайдера.
